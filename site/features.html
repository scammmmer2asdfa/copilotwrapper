Features

What Copilot Desktop actually does, not what any browser tab already does worse.

Real codespace tabs

The icon rail lists your open codespaces as tabs, persisted across restarts. The `+` button opens a picker backed by the real gh api user/codespaces call — not a mock, not cached data.

No browser keybinding theft

Each tab embeds the codespace's own github.dev web editor directly in an Electron <webview>, inside a dedicated app window with no browser chrome capturing shortcuts before the editor sees them.

A real terminal, not a log

A PTY-backed terminal panel (node-pty + xterm.js, the same stack VS Code uses) for running local commands, completely independent of any codespace tab.

Right Shift → quick browser

Press Right Shift anywhere to pop up a small in-app browser — a URL bar plus back/forward/reload — for visiting any site without leaving the app. Press it again to close.

No token handling

Listing and opening codespaces both shell out to the gh CLI you already have signed in. This app never sees, stores, or transmits a GitHub token itself.

Five themes, one token set

Graphite, Paper, and three real GitHub Primer palettes (Dark, Dark Dimmed, Light) — all driven by the same CSS custom properties, shared with this site.

How it works

  1. 1

    Ask gh for your codespaces

    gh api user/codespaces returns each codespace's name, repository, state, and — the important part — its real web_url.

  2. 2

    Embed it directly

    That URL goes straight into an Electron <webview> as a new tab — the exact same editor github.dev serves, just inside a native window.

  3. 3

    Keep your own tools alongside it

    A real local terminal and a quick in-app browser are one click (or one keypress) away, independent of whatever codespace tab is active.
