A native shell for GitHub Copilot CLI.

Copilot Desktop drives the real copilot --acp agent over its own Agent Client Protocol — no scraped terminal output, no reimplemented chat engine. Sessions, queued messages, tool permissions and plans, all in a proper desktop UI.

Real ACP, not a guess

Speaks newline-delimited JSON-RPC directly to copilot --acp: initialize, session/new, session/prompt, live session/update streaming, and permission requests.

Never drops a message

Messages sent mid-turn are queued per-session in SQLite and dispatched in order once the current turn finishes — including recovery if the app crashes mid-send.

Your editor, your call

Jump from a tool call straight into VS Code, Cursor, Zed, Sublime, WebStorm, vim, or any custom binary you configure.

You approve every tool call

Permission requests from the agent block the turn until you respond — allow once, allow always, or reject — right where the tool call happened.

Sign in, no tokens in sight

Runs the CLI's own copilot login device-code flow and shows you the code. The token exchange stays entirely inside the CLI process.

Two themes, one token set

Graphite and Paper are both driven by the same CSS custom properties — the app and this site share the exact same design tokens.

How it works

  1. 1

    Spawn the real CLI

    The Electron main process launches copilot --acp as a child process.

  2. 2

    Speak its protocol

    Newline-delimited JSON-RPC over stdio — initialize, session/new, session/prompt — with streamed session/update notifications.

  3. 3

    Render it properly

    Agent messages, thoughts, plans and tool calls land in a real React UI, not a terminal pane.

FAQ

Is this an official GitHub product?

No. Copilot Desktop is an independent, unofficial client that wraps the official @github/copilot CLI. It is not affiliated with or endorsed by GitHub.

Do I need my own Copilot subscription?

Yes — the app shells out to the real CLI's own login and subscription checks; it doesn't provide any access on its own.

Where does my code and chat history live?

Locally, in a SQLite database in your OS's app-data directory. Nothing is sent anywhere except what the Copilot CLI itself sends as part of a normal session.

Which platforms are supported?

macOS (Apple Silicon and Intel), Windows x64, and Linux x64, each bundling only its own platform's CLI binary.
