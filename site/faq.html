FAQ

Is this an official GitHub product?

No. Copilot Desktop is an independent, unofficial shell for GitHub Codespaces. It is not affiliated with or endorsed by GitHub.

How does it access my codespaces?

It shells out to the real gh CLI (gh api user/codespaces), the same tool you'd use in a terminal. It uses whatever account you already have signed into gh — this app never handles a GitHub token itself.

Do I need the `gh` CLI installed?

Yes, and signed in (gh auth login) — the codespace picker calls it directly. If it's missing or unauthenticated, the picker shows that error instead of a list.

Is there a real terminal in the app, or just a log?

A real one. The bottom panel's Terminal tab is backed by node-pty spawning an actual shell process, rendered with xterm.js — the same combination VS Code's own integrated terminal uses. It's independent of any codespace tab.

What does Right Shift do?

Toggles a small, transient in-app browser — type a URL, browse it embedded in the app, press Right Shift again (or Escape) to close it. It's not tied to any codespace tab and doesn't persist between launches.

Why not just use a browser tab for Codespaces?

Browsers intercept a lot of keyboard shortcuts (Ctrl+W, Ctrl+T, Cmd+, etc.) before a page running inside them ever sees the keystroke — a real, common annoyance for a browser-hosted editor like the Codespaces web UI. A dedicated app window has no such browser chrome capturing input first.

What themes are available?

Graphite and Paper (this app's own two), plus GitHub Dark, GitHub Dark Dimmed, and GitHub Light — real palettes from GitHub's public Primer design tokens.

macOS says the app "contains malware" / won't open — what do I do?

The macOS build isn't code-signed or notarized by Apple (that requires a paid Apple Developer Program membership this project doesn't have), so Gatekeeper blocks it by default the same way it would any unsigned download. To run it anyway: open System Settings → Privacy & Security, scroll down, and click "Open Anyway". Alternatively, in Terminal: xattr -cr /Applications/Copilot Desktop.app to strip the quarantine flag. This isn't a bug in the app — it's expected for any unsigned open-source Mac app.
