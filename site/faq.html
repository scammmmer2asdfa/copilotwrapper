FAQ

Is this an official GitHub product?

No. Copilot Desktop is an independent, unofficial client that wraps the official @github/copilot CLI. It is not affiliated with or endorsed by GitHub.

Do I need my own Copilot subscription?

Yes — the app shells out to the real CLI's own login and subscription checks; it doesn't provide any access on its own.

Where does my code and chat history live?

Locally, in a SQLite database in your OS's app-data directory. Nothing is sent anywhere except what the Copilot CLI itself sends as part of a normal session.

Which platforms are supported?

macOS (Apple Silicon and Intel), Windows x64, and Linux x64, each bundling only its own platform's CLI binary.

How do I get the CLI itself?

You don't have to — the app bundles it. The actual copilot executables for all four supported platforms are committed directly in this repository (via Git LFS) under resources/copilot-cli/, so every installer and every dev clone already has what it needs with no separate download step.

Is there a real terminal in the app, or just a log?

A real one. The bottom panel's Terminal tab is backed by node-pty spawning an actual shell process, rendered with xterm.js — the same combination VS Code's own integrated terminal uses. It runs independently of whatever the agent is doing. The Agent Output tab next to it is different: a live, read-only stream of the agent subprocess's own stderr.

Can I give the agent project-specific rules?

Yes — Settings → Agent instructions reads and writes .github/copilot-instructions.md in the current session's directory, the same file the CLI's own /init command and repo-level instruction loading use.

What themes are available?

Graphite and Paper (this app's own two), plus GitHub Dark, GitHub Dark Dimmed, and GitHub Light — real palettes from GitHub's public Primer design tokens, matching VS Code's own GitHub Theme extension.

Does it check whether I have Node.js or the CLI installed?

On first launch, a setup screen shows what's detected: the bundled CLI (always present), any copilot already on your PATH, and your system Node.js/npm versions — with a one-click option to install the CLI globally if you want to use it from your own terminal too.

macOS says the app "contains malware" / won't open — what do I do?

The macOS build isn't code-signed or notarized by Apple (that requires a paid Apple Developer Program membership this project doesn't have), so Gatekeeper blocks it by default the same way it would any unsigned download. To run it anyway: open System Settings → Privacy & Security, scroll down, and click "Open Anyway" next to the message about Copilot Desktop (appears after the first blocked attempt). Alternatively, in Terminal: xattr -cr /Applications/Copilot Desktop.app to strip the quarantine flag. This isn't a bug in the app — it's expected for any unsigned open-source Mac app.
